# دليل إضافة نماذج ثلاثية الأبعاد (GLB)

## الوضع الحالي
المعمل يعمل الآن بنموذج **مُنشأ برمجياً** (أشكال هندسية تقريبية للأعضاء بـ Three.js). هو ثلاثي الأبعاد حقيقي (تدوير وتكبير ونقر)، لكنه **ليس نموذجاً تشريحياً دقيقاً**. لم يُضمَّن أي نموذج خارجي لأنّه لم يكن بالإمكان التحقق من تراخيص النماذج أو تنزيلها أثناء البناء.

## كيف تضيف نموذجاً أدقّ
1. ابحث عن نموذج جهاز هضمي بصيغة GLB/GLTF بترخيص يسمح بالاستخدام التعليمي (مثل CC0 أو CC-BY). أمثلة لمصادر: NIH 3D، Sketchfab (فلتر: Downloadable + الترخيص)، BodyParts3D (يحتاج تحويل). **اقرأ الترخيص بنفسك** وأضف الإسناد المطلوب (Attribution) في تذييل الموقع إن لزم.
2. اضغط حجم الملف (يفضّل < 5MB) بأداة `gltf-transform` أو `gltfpack`.
3. ضع الملف في: `public/models/digestive-system.glb`
4. افتح `src/features/lab3d/organs.ts` وعدّل `GLB_CONFIG.nodeMap` لتطابق **أسماء العقد (Nodes)** داخل ملفك (يمكن رؤيتها بفتح الملف في https://gltf.report).
5. شغّل الموقع: سيكتشف المعمل الملف تلقائياً ويستبدل النموذج البرمجي به، مع بقاء النقر والتمييز ولوحة المعلومات بالعربية.

> ملاحظة: منطق GLB مكتوب لكنه لم يُختبر بنموذج حقيقي لعدم توفّر نموذج مرخّص أثناء التطوير. اختبره بعد إضافة نموذجك.
